# System Prompt Template (Redacted)

> **Note**: The original system prompt content has been removed from this open-source release.
> Due to the organization's external disclosure policy, proprietary prompt templates
> cannot be publicly distributed.
>
> To use this project, you need to provide your own system prompt here. The prompt should:
> - Define the agent's role as a software engineering assistant
> - Specify the available tools and their usage conventions
> - Set behavioral guidelines (e.g., search before edit, test after edit)
> - Define output format and submission rules
>
> You can refer to open-source SWE agent prompts (e.g., from SWE-agent or OpenHands)
> as a starting point and adapt them to work with the tool schema in `tools.json`.
